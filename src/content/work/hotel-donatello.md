A real client project: a calm, warm website for a hotel in Montecatini Terme, Tuscany. Rooms, location and everything a guest needs before they book, with a small splash animation when you arrive.

Guests can leave a message in the guestbook, which I built with Firebase so the owners can see it straight away.
